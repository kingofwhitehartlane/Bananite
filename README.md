# 🍌 Bananite — Native Android App
A modern, native Android application for the **Mashhad University of Medical Sciences (MUMS)** food reservation system (`stufood.mums.ac.ir`).

## 📱 About Bananite

**Bananite** is designed for students at Mashhad University of Medical Sciences to manage daily and weekly meal reservations easily. Built using native **Kotlin** and **Jetpack Compose**, it offers a fast, smooth, and modern mobile experience that replaces tedious web portal navigation and legacy scripts.

---

## 🚀 Downloading & Installation

You do **not** need to install Android Studio or build the app from code! Pre-compiled, ready-to-use Android packages (**APK files**) will be published on the repository's Releases page.

### Quick Install Guide:
1. **Download APK:** Head over to the [**GitHub Releases Page**](https://github.com/kingofwhitehartlane/Bananite/releases) and download the latest `.apk` file (e.g., `app-release.apk`) to your Android device.
2. **Allow Unknown Sources:** When opening the downloaded `.apk` file for the first time, your phone may prompt you to allow installation from "Unknown Sources" or allow your browser/file manager to install applications.
3. **Install & Launch:** Tap **Install**, wait for completion, and open **Bananite** directly from your home screen or app drawer.

---

## ✨ Features

- 🍲 **Weekly Meal Reservation:** Select meals (Lunch/Dinner), pick your cafeteria, and reserve food for upcoming weeks.
- 🔄 **Food Exchange (تبادل غذا):** Integrated workflow for offering, exchanging, or transferring reservations with fellow students.
- 🎨 **Material 3 Customization:** Support for System Light/Dark themes, **OLED Pure Black** mode, dynamic Material You colors, and animation controls.
- 🔒 **Direct & Secure Sessions:** Handles server sessions cleanly without transmitting credentials to third-party services.
